# Kanban Project Management Tool

A simple Kanban-style task management application built with React, Node.js, Express, and SQLite.

##  Overview

This project helps users organize tasks into different workflow stages:

- To Do
- Doing
- Done

The application demonstrates full-stack development concepts including frontend development, backend API creation, database integration, authentication, and deployment.

##  Features

- User Login Authentication
- Create Tasks
- View Tasks
- Move Tasks between workflow columns
- REST API Backend
- SQLite Database Storage
- Responsive Interface

## ⚙️ Local Setup

### Clone Repository

```bash
git clone https://github.com/nikhiltiwari0214/project-manager.git
```

### Install Backend

```bash
npm install
node server.js
```

### Install Frontend

```bash
cd client
npm install
npm run dev
```
